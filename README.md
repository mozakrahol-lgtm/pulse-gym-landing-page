# PULSE GYM — Train Beyond Limits

A modern, responsive gym landing page designed to showcase fitness programs, premium facilities, membership plans, professional coaches, and a free-pass registration form.

## Project Overview

PULSE GYM is a gym landing page built using HTML5 and CSS3. It features a dark visual theme with orange accents, a clean layout, and responsive styling for different screen sizes.

## Features

* Responsive navigation bar
* Hero section with call-to-action buttons and gym statistics
* Training programs section
* Facilities and recovery section
* Membership plans
* Coaches section
* Member testimonials
* Free-pass registration form
* Responsive layout for desktop and mobile screens
* Smooth scrolling and hover effects

## Technologies Used

* HTML5
* CSS3
* CSS Grid
* Flexbox
* CSS Media Queries
* Git and GitHub for version control

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

No additional installation is required.

## Notes

* The free-pass registration form is a static demonstration and is not connected to a backend.
* Membership plans and gym information are sample content for demonstration purposes.
